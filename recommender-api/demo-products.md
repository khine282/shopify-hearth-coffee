# Demo products to create in Shopify admin

Products > Add product. For each: set the **Title** exactly as shown (Shopify
auto-generates the handle from it, which will match `catalog.js`), paste the
description, set the price, and add a placeholder image (any coffee bag photo
— Unsplash/Pexels, free to use). Set inventory to "don't track quantity" or
just add stock so it's purchasable in the demo.
